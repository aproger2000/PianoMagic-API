# v7.6.0: neural polyphonic transcription (Spotify Basic Pitch,
# ICASSP 2022 model). This is the primary engine; librosa/PYIN above
# is kept as the automatic fallback.
#
# Backend note: basic-pitch ships several inference runtimes and picks
# one at import (TensorFlow > CoreML > TFLite > ONNX). onnxruntime is
# pinned explicitly here because it's the smallest and most portable
# of them on a Linux container - installing full TensorFlow would add
# well over half a gigabyte to the image for no accuracy gain.
#
# v7.6.1: use the [onnx] extra rather than bare basic-pitch plus a
# separate onnxruntime pin. In v7.6.0 the package imported fine but
# inference threw on every request, and installing the runtime alongside
# the package is not the same as telling the package which runtime it is
# built for - the extra pulls the matching model assets too, so the
# selected backend and the bundled graph can't disagree.
basic-pitch[onnx]>=0.4.0
onnxruntime>=1.16.0
